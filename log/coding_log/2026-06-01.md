# Coding Log — 2026-06-01

## 重要：DeepSeek reasoning_content surrogate 字符修复

- DeepSeek 的 `reasoning_content` 字段偶尔包含 UTF-16 surrogate 字符（如 `\udce4`），Python 字符串中可以合法存储，但序列化为 JSON 并编码为 UTF-8 时抛出 `UnicodeEncodeError: surrogates not allowed`
- 修复：在 `agent/loop.py` 中添加 `_sanitize()` 函数，用正则 `[\ud800-\udfff]` 剥离所有 surrogate 字符
- 对所有进入 `self.messages` 的字符串（API 响应的 content / reasoning_content / tool_call 参数、用户输入）都经过 sanitize
