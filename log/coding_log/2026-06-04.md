## 重要：日志系统扩充 — LLM 调用/审批决策/工具调用/上下文压缩

在 3 个模块加入结构化日志，补齐项目"只有 1 条日志"的短板。

### LLM 调用日志 (`agent/loop.py`)

- `_call_llm`：记录 model、duration_ms、prompt_tokens、completion_tokens（从 response.usage 提取）
- `_call_llm_streaming`：同上，usage 从最后一个 stream chunk 的 `chunk.usage` 提取（需 `include_usage`）
- `_call_with_retry`：每次重试时记录 `llm_call retry attempt=N/N reason=...`

### 审批决策日志 (`safety/approval.py`)

- 硬拦截 DENY：`approval=deny reason=hardline` WARNING
- 用户确认 ALLOW：`approval=allow reason=user_confirm` INFO
- 用户拒绝 DENY：`approval=deny reason=user_reject` INFO
- 非交互模式 DENY：`approval=deny reason=non_interactive` INFO
- 未命中模式不记录（太吵）
- command 截断到 120 字符

### 工具调用日志 (`tool/registry.py`)

- `dispatch()` 每次调用记录工具名、状态（ok/error/unknown_tool）、耗时
- 不记录参数和返回值（防泄漏、防日志膨胀）
- 不违反 tool/ 零依赖原则（仅用 stdlib `logging.getLogger`）

### 上下文压缩日志 (`agent/loop.py`)

- Phase 1（截断 tool 内容）：记录前后字符数
- Phase 2（删除中间组）：记录前后字符数和删除组数
- Phase 2 以 WARNING 级别记录（更严重的事件）
